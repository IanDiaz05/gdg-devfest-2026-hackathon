## Orden recomendado

1. **Integración y exactitud.** API-01, API-02 y LOC-01. Verificar la API antes de habilitar datos reales.
2. **Funcionalidad y responsive.** FUN-01 y RESP-01. Repetir la matriz de anchuras, teclas y estados de error.
3. **Ajustes visuales y regresión.** UX-01 y QA-01. Aplicar el wireframe con los campos verificados y dejar comprobaciones reproducibles.

Para el primer pase, frontend 1 puede tomar RESP-01 y UX-01 mientras frontend 2 coordina API-01 y prepara API-02. El trabajo sobre la ubicación se coordina entre ambos.
